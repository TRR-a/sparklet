## English
# Sparklet v0.2.1 Release Notes
*Internal Codename: Water*

---

## ✨ What's New
1.  Added full multi-language support, expanded to 9 languages with real-time full-window synchronization: Simplified Chinese, English, Japanese, Korean, French, Russian, Spanish, German, Brazilian Portuguese
2.  Added independent About window and DevTools window
3.  Added macOS-style traffic light window control buttons, with complete custom window control logic
4.  Added global theme broadcast to synchronize light/dark mode across all windows in real time
5.  Added pop-up feedback for successful language switching

## 🎨 Experience & Visual Improvements
1.  Implemented glassmorphism design for Settings and About windows
2.  Added multi-layer gradient soft light halo effect for the settings window
3.  Optimized text display effect for both light and dark themes
4.  Optimized the blur relationship and interaction logic between the main window and the settings panel
5.  Optimized title bar layout and centered display of the settings panel title
6.  Simplified the prompt for successful language switching
7.  Cleaned up useless code comments, improved CSS style comments, and optimized JS event binding

## 🔧 Technical & Configuration Updates
1.  Set appId as a permanent configuration to prevent user data loss during subsequent version updates

## ⚠️ Precautions

- After installing v0.2.1, if you have previously installed an older version (v0.1.0 or v0.2.0), please open the older version first, manually migrate your note content and custom configurations to v0.2.1, and then delete the old version.

- **If you fail to save your data following this author-verified procedure, the author shall not be held liable for any data loss or corruption.**

# Sparklet v0.2.1 发布说明
*内部版本代号：Water*

---

## ✨ 新增功能
1.  新增完整多语言支持，扩展至9国语言全窗口实时同步：简体中文、英语、日语、韩语、法语、俄语、西班牙语、德语、巴西葡萄牙语
2.  新增独立的关于窗口与 DevTools 窗口
3.  新增 Mac 风格红绿灯窗口控制按钮，完整自定义窗口控制逻辑
4.  新增主题全局广播，实现所有窗口亮暗色模式实时同步
5.  新增语言切换成功弹窗反馈

## 🎨 体验与视觉优化
1.  为设置窗口、关于窗口实现玻璃拟态设计风格
2.  为设置窗口新增多层渐变柔光光晕效果
3.  优化深浅主题下的文字显示效果
4.  优化主窗口与设置面板的虚化关系与交互逻辑
5.  优化标题栏布局与设置面板标题居中显示
6.  精简语言切换成功提示内容
7.  清理代码中无用注释，完善 CSS 样式注释，优化 JS 事件绑定

## 🔧 技术与配置更新
1.  将 appId 设为永久配置，防止后续版本更新丢失用户数据

## ⚠️ 注意事项

- 安装 v0.2.1 版本后，若您曾安装过旧版本（v0.1.0 或 v0.2.0），请先打开旧版本，手动将笔记内容与自定义配置迁移至 v0.2.1 中，再删除旧版本。

- **若未按照上述作者已验证的方案操作导致数据异常或丢失，作者概不负责。**
